### Is XCutors free to use?

Some executors in the collection are free, while others may require a separate license key. Check each executor's individual documentation for pricing and licensing details.

### What are the system requirements?

XCutors requires Windows 10 or later, a minimum of 4 GB RAM, .NET Framework 4.8 or higher, and administrator privileges for script injection functionality.

### How do I update the executors?

The universal loader includes a built-in auto-update feature. Simply launch xcutorsLoader and it will automatically check for and apply any available updates to your installed executors.

### Can I add my own custom scripts?

Yes. You can load custom Lua scripts from local files on your computer or paste script code directly into the built-in script editor for immediate execution.

### Why is my anticomponent flagging the loader or executors?

Some anticomponent software may flag script executors due to their memory injection behavior. You may need to add an exclusion for the XCutors installation folder. Always ensure you download only from the official repository to avoid tampered files.

### Which Roblox versions are supported?

XCutors is regularly updated to maintain compatibility with the latest stable Roblox client versions. Refer to the Releases page or the in-app changelog for current version compatibility information.

### How do I switch between different executors?

Open xcutorsLoader and use the executor selector panel on the main interface. Each executor can be launched independently, and you can switch between them without restarting the loader.
